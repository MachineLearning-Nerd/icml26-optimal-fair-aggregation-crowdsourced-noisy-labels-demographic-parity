# Thank you to the authors

Thank you to Gabriel Singer, Samuel Gruffaz, Olivier Vo Van, Nicolas Vayatis,
and Argyris Kalogeratos for making the fairness definitions, aggregation
rules, convergence claims, and post-processing method available for
independent examination.

The paper's separation of Majority Vote, Bayes aggregation, and fairness
post-processing made it possible to preserve the historical homogeneous-skill
baseline while adding an exact heterogeneous audit with explicit controls. The
repository reports the finite and reconstructed parts separately so readers
can see exactly what the evidence supports.

This is an independent reproduction archive, not an authors' implementation or
endorsement. Please cite both the paper and this repository when using the
code or evidence; see [`CITATION.cff`](CITATION.cff).
